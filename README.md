# 💼 Salary Analysis Project

This project explores and analyzes salary data to uncover patterns and insights about compensation.  
It was completed as part of my learning journey in data analytics and demonstrates skills in **Python, data wrangling, and visualization**.

---

## 📌 Project Overview
- Goal: Understand factors that influence salaries and practice exploratory data analysis (EDA)  
- Language/Tools: **Python** (Jupyter Notebook, Pandas, Matplotlib/Seaborn)  
- Notebook: [`salary_analysis.ipynb`](./salary_analysis.ipynb)  

---

## 🔧 Key Steps
1. **Data Cleaning**  
   - Handle missing values  
   - Fix data types  
   - Remove duplicates  

2. **Exploratory Data Analysis (EDA)**  
   - Distribution of salaries  
   - Comparison across job roles, industries, and experience levels  
   - Gender and location-based salary gaps  

3. **Visualization**  
   - Histograms, boxplots, bar charts for comparison  
   - Scatter plots for salary vs. experience/education  

---

## 🚀 Next Steps

- Compare results across different ML approaches  
- Build an interactive dashboard for salary exploration
